### Present

- **Tour operations platform** (private client, .NET 9): support and booking backend for a tour operator. Includes a customer-support agent that answers website chat by calling FAQ-retrieval tools, behind a deterministic router that decides whether each reply goes to the customer or to staff for review. Also LLM-based ticket triage and document parsing, an ERP bridge for bookings and availability, and an MCP server that exposes these operations to internal AI agents. ASP.NET Core, Semantic Kernel, Azure OpenAI, PostgreSQL, MongoDB, self-hosted LibreChat and Activepieces, Docker, Azure DevOps CI/CD.
- **Game development studies**: following a self-directed, multi-year curriculum, building games in C without an engine, with a focus on simulation and gameplay systems programming. The goal is an original game set in a simulated fantasy world, where a working economy and other interacting systems drive what happens instead of scripted events.

- **Public-Sector Payroll System**: backend developer on a thick-database Oracle stack, maintaining and extending a payroll system for a large government organization, originally built circa 2005. All payroll logic implemented in PL/SQL on Oracle Database, with an Oracle Forms front-end.
