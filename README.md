### Present

- **Tour operations platform** (private client, .NET 9): the support and booking backend for a tour operator. Its customer-support agent answers website chat by calling FAQ-retrieval tools, and a deterministic router in front of it decides whether each reply goes straight to the customer or to staff for review. The platform also uses LLMs to triage tickets and parse documents, connects to the operator's ERP for bookings and availability, and exposes these operations to internal AI agents through an MCP server.<br>
  _ASP.NET Core, Semantic Kernel, Azure OpenAI, PostgreSQL, MongoDB, self-hosted LibreChat and Activepieces, Docker, Azure DevOps CI/CD_

### Past

- **[BAM Engine](https://github.com/kganitis/bam-engine)**: an agent-based macroeconomics framework in Python. It simulates households, firms, and banks interacting across labor, credit, and goods markets, running on a vectorized NumPy core with an ECS design.
- **Public-sector payroll system**: backend developer maintaining and extending the payroll system of a large government organization. The system runs on a thick-database Oracle stack from around 2005, with all payroll logic in PL/SQL and an Oracle Forms front end.
- **Internal security tooling**: in-house tools for the cybersecurity department of a large organization, used for monitoring, technical security assessments, and information-security compliance work.
